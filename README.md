# python_project_3

🎓 Student Data Organizer

📌 Project Overview

Student Data Organizer is a menu-driven Python application designed to manage student information in an organized way.

The project demonstrates the practical use of Python Collections such as:

- List
- Dictionary
- Set
- String
- Loop
- Conditional Statements
- User Input

---

🚀 Main Features

1️⃣ Add Student

Allows the user to enter complete student information:

- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects

2️⃣ Display All Students

Shows all student records stored during the current program execution.

3️⃣ Unique Subject Management

Subjects are stored using a Set, so duplicate subjects are automatically removed.

Example:

Python, Maths, Python, Physics

is stored as:

{'Python', 'Maths', 'Physics'}

4️⃣ Interactive Menu

The program continuously displays a menu until the user selects Exit.

---

🧠 Data Structure Concept

The project uses a combination of Python collections.

Student List
     │
     ├── Student Dictionary
     │      ├── Student ID
     │      ├── Name
     │      ├── Age
     │      ├── Grade
     │      ├── DOB
     │      └── Subjects Set
     │
     └── More Student Records

List

Stores multiple student records.

Dictionary

Stores information belonging to one student using key-value pairs.

Set

Stores unique subjects without duplicates.
